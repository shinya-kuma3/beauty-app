# 美容の編集方針（2026-10-14）

美容の話題、トレンド、使い方、商品紹介、使い心地、個人の体験談を扱います。研究・論文・科学的根拠の有無は掲載条件ではありません。

## 記事と参考リンク

- 科学的根拠の読み方を主題にした記事は公開対象から外しました。
- 成分図鑑の研究解説は、名称・使われ方・製品選びの話に整理しました。
- 論文、学会・医学団体のガイドライン、科学的根拠へのリンクは公開サイトに表示しません。既存の静的コンテンツからも削除しました。
- 参考にしたX・YouTubeへのリンクは残します。参考リンクは任意で、Xだけ・YouTubeだけでも掲載できます。
- 参考リンクがない記事も登録・編集・公開できます。URLを記載する場合のHTTPS形式、記事の版管理、人による公開承認は維持します。

科学的リンクの表示除外はshared/editorial-policy.mjsにまとめています。既存の種別guideline/researchと、既知の論文・医学資料の公開元を判定します。X・YouTubeのリンクはタイトルに研究の語があっても残します。科学的な資料の新しい公開元を見つけた場合は判定リストに追加してください。科学資料のすべてを未知のURLから自動判定できるものではありません。

## APIの変更

- POST /api/ingest/articles: citationsは省略または空配列可、ai_check_notesは省略または空文字可。科学的な文献や確認メモは必須ではありません。
- 管理画面の参考URL・編集メモも任意です。
- Grokの再チェック結果: checked_citationsとprimary_source_notesは省略可。既存Botの同名フィールドも互換性のため受け付けます。論文の確認義務を意味しません。
- 科学的根拠不足を理由とする公開制限を削除しました。X・YouTube以外のリンクを要求する条件も削除しました。
- 成分・記事の静的JSONとGitの承認記事もsources=[]を許可します。

海外のWeb素材のtype=researchは既存DBとの互換性のため残っています。一般の美容記事にも使える技術的な区分で、論文の収集や掲載を必須にするものではありません。

## AIの役割

Grok Botは美容の話題を日本語の記事に整理し、読みやすさ・表記・紹介内容・PR表示を確認します。科学的根拠がないことを警告・公開停止の理由にしません。元の投稿にない体験や、見ていない動画の内容を創作しないでください。

本番反映前のGrokチェックは、人が承認した記事とGitに保存する記事の内容の一致を確認します。学術資料による再審査を行う条件は削除しました。

Geminiの動画要約は商品・成分・紹介内容・体験談の補足・タイムスタンプ・原語表記を残します。科学的根拠の探索は要求しません。Workers AIのタグ候補から研究を外しました。

## 外部Botへの反映

外部のGrok Botにはdocs/grok-editorial-policy-prompt.txtを渡してください。WorkerのAPIが返すチェック指示も変更しています。既存の下書き本文や履歴は自動で書き換えず、必要なら管理画面で修正してください。
